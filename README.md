# Retail Sales Analytics Dashboard

## Project Overview

This project analyzes retail sales data using Excel and MySQL to identify sales trends, customer behavior, regional performance, and profitability insights. The project includes data cleaning, SQL-based business analysis, an interactive dashboard, and a business insights report.

## Objective

The objective of this project is to transform raw retail sales data into meaningful business insights that can support data-driven decision-making.

## Tools Used

* Microsoft Excel
* MySQL
* MS Word
* Data Visualization

## Project Workflow

1. Data Cleaning and Preparation in Excel
2. Data Analysis using SQL Queries
3. Business Insights Report Creation
4. Dashboard Development using Pivot Tables, Charts, and Slicers
5. Business Recommendations

## Key Insights

* Total Sales: ₹32,912.92
* Total Profit: ₹1,587.82
* Top Performing Region: West
* Most Profitable Category: Office Supplies

## Dashboard Features

* KPI Cards
* Sales by Region Analysis
* Profit by Category Analysis
* Top Customer Analysis
* Sales Trend Analysis
* Interactive Slicers
